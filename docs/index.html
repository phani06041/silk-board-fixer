How it works

The loop

Plan

For each scenario the agent writes the green time for every approach in every 15-minute window. It runs on TrueForge, through the TrueFoundry AI Gateway.

Simulate

A deterministic simulator plays out the hour second by second: arrivals, discharge, queues, gridlock. The 3D view above runs that same simulator in your browser.

Read the report

Per window and approach: vehicles in and out, waits, longest queue and the measured flow per lane. No answers, only what happened.

Rewrite itself

The agent rewrites its playbook and commits it with its session ID. Scenarios and scorer stay frozen, so every run is measured the same way.
